# Early establishment and life course stability of sex biases in the human brain transcriptome

This repository contains codes used to study transcriptomic sex differences in prenatal and adult human brain.
The results of this analysis are presented in the following paper: 

Benoit-Pilven C, Asteljoki JV, Leinonen JT, Karjalainen J, Daly MJ, Tukiainen T. Early establishment and life course stability of sex biases in the human brain transcriptome. *Cell Genomics*. 2025;5(7):100890.
doi:[10.1016/j.xgen.2025.100890](https://doi.org/10.1016/j.xgen.2025.100890)

## Data

`data/3-DE/fitmm_dream_pseudotime_sva_ind_interaction_phenotypes.RData` (151 MB) is too large for GitHub and is available on Zenodo: [10.5281/zenodo.24365895](https://doi.org/10.5281/zenodo.24365895). Download it into `data/3-DE/` to run the downstream scripts.
